# CATUC Programming 1 Assignment

This repository contains the two Python programs required for the Programming 1 assignment.

## Files

1. `shop_receipt.py` — collects each item's name, quantity and unit price; calculates each item total, applies the class discount rules, and prints a receipt.
2. `multiplication_division_tables.py` — asks the user for a number and a limit, then dynamically displays its multiplication and division tables.

## How to run

Open a terminal in this folder and run:

```bash
python shop_receipt.py
```

or:

```bash
python multiplication_division_tables.py
```
